# DeepMindQ Competitive Battle Cards

Internal documentation of unique capabilities for competitive positioning.

## Overview

This directory contains battle cards — concise, sales-ready documents that
articulate DeepMindQ's unique differentiators against common competitor
categories. These cards are designed for account executives and solution
engineers to use in competitive deal situations.

## Card Categories

| Category | File | Competitor Profile |
|----------|------|--------------------|
| AI-Native Platforms | `ai-native-platforms.md` | AI-first sales tools (e.g., Apollo.io, Clari, Gong) |
| Traditional CRM Analytics | `traditional-crm-analytics.md` | CRM add-ons and analytics suites |
| Point Solutions | `point-solutions.md` | Single-function tools (e.g., enrichment-only, scoring-only) |
| Enterprise BI Platforms | `enterprise-bi-platforms.md` | BI/reporting tools repurposed for sales intel |
| DIY/In-House Builds | `diy-builds.md` | Custom internal tools built by prospect engineering teams |

## Usage Guidelines

- Battle cards are for INTERNAL USE ONLY — do not share with prospects
- Update quarterly or when significant feature releases occur
- Each card follows a standard structure: Position, Key Differentiators, Proof Points, Objection Handling
- For the latest product capabilities, cross-reference with the public roadmap
