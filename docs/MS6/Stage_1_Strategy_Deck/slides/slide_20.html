Each screen development must pass 5 questions: Is this important? · What should the user do? · Why trust this? · Does the user have control? · Does this match the Design DNA?

MS6 does not build screens. MS6 builds the foundation that governs how screens are built. Each subsequent milestone extends the design DNA. The 5-question gate ensures consistency: before any screen is developed in MS7-MS11, it must answer these five questions. This prevents scope creep and design drift.
